# Alhidayah WordPress theme

The Alhidayah storefront as a WooCommerce + Elementor WordPress theme, matched pixel for pixel to the Next.js site.

- `dist/alhidayah.zip`: upload under **Appearance → Themes → Add New → Upload Theme**.
- `dist/alhidayah-core.zip`: companion plugin (Forms inbox, testimonials, Elementor widgets, SEO). It is also bundled inside the theme and installed in one click from **Appearance → Alhidayah Setup**.
- `alhidayah/`, `alhidayah-core/`: source. See `alhidayah/readme.txt` for installation and editing.

After activating: Appearance → Alhidayah Setup → install Alhidayah Core, WooCommerce and Elementor → **Import demo content**.
Orders arrive in WooCommerce → Orders; contact form messages arrive in **Forms**.
