Premium fragrance storefront theme for WooCommerce and Elementor.

== Description ==

Alhidayah is a premium perfume and fragrance store theme: a warm amber hero, scent collections,
a filterable product showcase, testimonials, a product detail page, a Shopify-style one-page
checkout and a contact page whose inquiries land in the dashboard under "Forms".

= Features =

* WooCommerce: products, categories (scent families), AJAX shopping bag drawer, custom product page,
  Shopify-style checkout and order confirmation. Orders appear in WooCommerce → Orders.
* Elementor: every home page section is an Elementor widget (Hero, Collections, Ingredients, Products,
  Testimonials, Call to Action, Contact Form) in the "Al-Hidayah" category. Requires the bundled
  Alhidayah Core plugin.
* Forms: contact form submissions are saved under Forms in the dashboard (unread badge, mark read,
  reply by email or WhatsApp, CSV export) and emailed to you.
* One-click demo import: Appearance → Alhidayah Setup.
* Customizer: brand, announcement, hero, contact details, WhatsApp, footer and social links.
* Smooth scrolling and scroll animations that respect "reduce motion".

== Installation ==

1. Appearance → Themes → Add New → Upload Theme, choose alhidayah.zip, then Activate.
2. Open Appearance → Alhidayah Setup.
3. Click "Install & activate" next to Alhidayah Core (bundled), and install WooCommerce
   (required) and Elementor (recommended).
4. Click "Import demo content". Your store, products, pages, menus and checkout are ready.
5. Add a payment method under WooCommerce → Settings → Payments (Cash on delivery is enabled by the import).

If the upload stops with "The link you followed has expired", your host's upload limit is below the
theme size (about 4 MB): ask your host to raise upload_max_filesize, or unzip alhidayah.zip and upload
the alhidayah folder to wp-content/themes by FTP, then activate it under Appearance → Themes.

= Editing =

* Home page: Pages → Home → Edit with Elementor. Each section's text, images and buttons are editable.
* Products: WooCommerce → Products. The "Alhidayah" tab holds mood, accords, notes, size, story,
  card tint and the New / Best seller / Limited flags. Product image = bottle cut-out (transparent),
  first gallery image = lifestyle photo.
* Collections: Products → Categories. Set a thumbnail for the collection card photo.
* Testimonials: Testimonials menu (role, star rating, card tone).
* Contact details: Appearance → Customize → Al-Hidayah → Contact.

== Frequently Asked Questions ==

= Where do contact form messages go? =
To Forms in the dashboard, and an email is sent to the address set in Customize → Al-Hidayah → Contact
(or the site admin email).

= Where do orders go? =
WooCommerce → Orders, like any WooCommerce store.
